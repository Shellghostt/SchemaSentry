# Public rule reference

Generated by `make docs` from the same metadata as `schemasentry rules` and `explain`. The M3 internal classifier still uses its original seven-rule registry. M4 assessment uses all ten rules.

| Rule | Default base severity | Meaning |
|---|---|---|
| [SS001](SS001.md) | critical | Column removed |
| [SS002](SS002.md) | high | Column type changed |
| [SS003](SS003.md) | high | NOT NULL added without validated evidence |
| [SS004](SS004.md) | medium | Foreign-key supporting index unproven |
| [SS005](SS005.md) | high | Locking or rewriting statement |
| [SS006](SS006.md) | high | Column rename declared |
| [SS007](SS007.md) | medium | Default volatility |
| [SS008](SS008.md) | high | CHECK or foreign key validation requested |
| [SS009](SS009.md) | high | Index creation blocks writes |
| [SS010](SS010.md) | critical | Enum membership removed or renamed |

Each report retains base severity, final risk, confidence and modifier evidence separately. No finding or exit 0 establishes general safety.
