# 0067-enum-label-addition

Adding a known label does not remove prior membership. This negative case preserves the explicit input labels and does not infer them from column type text.

Expected values are independently reviewed policy/evidence assertions, committed before rule implementation.

PostgreSQL reference: [https://www.postgresql.org/docs/16/sql-altertype.html](https://www.postgresql.org/docs/16/sql-altertype.html).
