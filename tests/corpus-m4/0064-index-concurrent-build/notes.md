# 0064-index-concurrent-build

A supported concurrent build outside an explicit transaction avoids the ordinary-build finding. Multiple phases, lock waits and possible invalid leftovers remain explicit limitations.

Expected values are independently reviewed policy/evidence assertions, committed before rule implementation.

PostgreSQL reference: [https://www.postgresql.org/docs/16/sql-createindex.html](https://www.postgresql.org/docs/16/sql-createindex.html).
